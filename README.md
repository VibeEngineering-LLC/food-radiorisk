# food-radiorisk

Калькулятор ожидаемой эффективной дозы и стохастического риска от употребления продуктов питания,
загрязнённых радионуклидами. Аудитория — эксперт: все параметры открыты, у каждого числа указан источник.

## Цепочка расчёта

1. Удельная активность продукта, Бк/кг: измерена, либо оценена из плотности загрязнения почвы
   (коэффициенты перехода IAEA TRS-472), либо грубо из мощности дозы на месте сбора.
2. Кулинарная обработка: коэффициент удержания Fr и выход продукта Pe (TRS-472, TECDOC-1616).
3. Рацион: масса порции, число порций, период (разово / сезон / год).
4. Поступление, Бк → ожидаемая эффективная доза E = Σ I·e(g) по возрастной группе.
5. Риск по линейной беспороговой модели: R = E · r (ICRP 103 / НРБ-99/2009).
6. Сравнение с нормативами РФ (ТР ТС 021/2011, СанПиН 2.3.2.1078-01, НРБ-99/2009) и зарубежными.

## Устройство

- `src/calc/` — расчётное ядро, чистые ES-модули без DOM.
- `src/react/`, `src/ui/`, `index.html` — интерфейс на React (Vite): окно с вкладками ввода слева, результатом справа и строкой состояния; `src/ui/window.css` — вид окна настольной программы.
- `public/data/*.json` — справочные данные, собираются скриптами `tools/` из `data-src/`.
- `tools/calc_ref.py` — независимая реализация расчёта на Python для пересчётной проверки.
- `tests/` — тесты: `npm test` (встроенный `node --test`).
- `docs/` — собранный сайт (то, что отдаёт GitHub Pages).
- `data/local/` — локальные данные ICRP Electronic Annex; в git не входят (лицензия ICRP).

## Запуск

```bash
npm install
npm run dev
```

Сборка сайта: `npm run build` → каталог `dist/` (статические файлы, открываются любым статическим сервером).

## Источники данных

Каждое число в `public/data/*.json` несёт поля `source` и `loc` (страница, таблица или строка).
Результаты, полученные с данными ICRP Electronic Annex, должны ссылаться на него как на источник данных.
